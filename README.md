# Bella Vista Salon

## EGN 475 – Week 3 Assignment 3.1

Bella Vista Salon is a Flask web application developed as part of the EGN 475 Week 3 assignment. The application converts the Week 2 static mockup into a multi-page Flask application.

## Features

- Home page
- Services page displaying salon services
- Individual service detail pages
- Booking form
- Staff calendar
- Appointment history
- Custom 404 error handling

## Technologies Used

- Python 3.12
- Flask
- HTML
- CSS
- Pico CSS
